# Alexandria News Website

A bold purple JavaScript news website built with React and Vite.

## GitHub repository

Upload this project to your repository named:

`Alexandria`

Your website will publish at:

`https://tacobellmedia.github.io/Alexandria/`

## Publish it

1. Open the `Alexandria` repository on GitHub.
2. Upload every file and folder from this project.
3. Open **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. Push or upload the files to the `main` branch.
7. The included workflow will build and publish the website automatically.

## Edit stories

Open:

`src/main.jsx`

Change the articles inside the `stories` JavaScript array.

## Run locally

```bash
npm install
npm run dev
```
